# 楽天RSS LAN Monitor

楽天RSSを受信しているExcelをメインPCで読み取り、同じ家庭内LANにある別PCの
ブラウザへリアルタイム表示する監視ツールです。付属の軽量版Excelを使用します。

## できること

- `DB` シートの最大100銘柄を約5秒ごとに表示
- 現在値、前日比、VWAP乖離、日中高安位置、売買代金、気配を一覧化
- 売買代金、前日比、VWAP乖離などで並べ替え
- 価格履歴をSQLiteへ保存し、直近3時間の簡易チャートを表示
- 上限価格、下限価格、前日比上限・下限のアラート
- 始値比、VWAP比、年初来・上場来の高値安値差分アラート
- 各アラート条件を個別チェックでON/OFF
- 一覧のスイッチから銘柄単位のアラートをワンクリックON/OFF
- ★銘柄のお気に入り監視
- RVOL、直近15分の騰落率・売買代金増分
- 売買代金、RVOL、高値接近を組み合わせた「⚡注目」タブ
- 年初来・上場来の高値安値更新を記録する「ブレイク」タブ
- アラート12条件と寄前GU/GDの専用タブ、Config初期値を使う調整可能なフィルター
- 寄前GU上位・寄前GD上位をGU/GD率で抽出・並べ替え
- 騰落銘柄数と推定資金流入・流出ランキングの分析画面
- スマートフォン向けのカード表示・横スワイプタブ・全画面設定ダイアログ
- ブラウザ通知（許可した端末のみ）
- 時刻に応じた東証 / PTS（JNX）自動切替

PTSと東証の切替状態は、画面右上のバッジにExcelの実データから表示されます。
時刻上の想定とExcelの状態が異なる場合は「要確認」と表示されます。

### 東証 / PTSの手動切替

Excelの `Config` シートに次の3ボタンがあります。

- `自動`: 06:00〜15:30は東証、それ以外はPTSへ自動切替
- `東証`: 時刻に関係なく東証へ固定
- `PTS`: 時刻に関係なくPTSへ固定

手動モードはブックを閉じても保持されます。時刻による自動切替へ戻すときは
必ず `自動` ボタンを押してください。選択状態と次回切替時刻はボタン上部に表示されます。

## ExcelのConfigシート

元のExcelには `Config` シートを追加しています。黄色の「初期値」列を変更すると、
アプリは数秒以内に新しい設定を読み取ります。

- 上限・下限価格: 現在値から何%離した価格を初期値にするか
- その他の条件: アラート設定画面と条件別タブで使う初期%

個別銘柄の設定を保存した後は、その銘柄には保存済みの値が使われます。
条件別タブのパネル変更はブラウザ上の一時的な絞り込みで、ExcelのConfig値自体は変更しません。

## 起動

1. メインPCでマーケットスピード II と楽天RSSを起動します。
2. Excelで `楽天RSS｜株式銘柄監視用｜軽量版.xlsm` を開きます。
3. `start.bat` をダブルクリックします。
4. メインPCでは `http://127.0.0.1:8765` を開きます。
5. 別PCでは `http://192.168.0.13:8765` を開きます。

初回起動時のみ、Python仮想環境と必要パッケージを自動セットアップします。

## Windowsファイアウォール

別PCから開けない場合は、Windows Defender ファイアウォールで
「プライベート ネットワーク」に対するPythonの通信を許可してください。
家庭内LAN以外へ公開する用途ではありません。ルーターのポート開放はしないでください。

## 設定

環境変数で変更できます。

```bat
set RAKUTEN_RSS_PORT=8765
set RAKUTEN_RSS_POLL_SECONDS=5
set RAKUTEN_RSS_HISTORY_SECONDS=10
set RAKUTEN_RSS_WORKBOOK=楽天RSS｜株式銘柄監視用｜軽量版.xlsm
set RAKUTEN_RSS_SHEET=DB
set RAKUTEN_RSS_DATA_RANGE=A1:AB101
set RAKUTEN_RSS_CONFIG_RANGE=A1:E30
set RAKUTEN_RSS_CONFIG_POLL_SECONDS=60
```

履歴とアラート設定は同じフォルダの `monitor.db` に保存されます。
履歴はTSE/PTS別に保存され、RVOLと直近15分分析も同じ市場区分の履歴だけを使用します。
Excelがセル編集中・計算中の場合は読取をスキップし、ブラウザには最後に取得できた値を表示します。
